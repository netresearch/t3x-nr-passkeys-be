- Confirm TYPO3's Sudo Mode dialog with a passkey instead of the password: before changing a password, creating an administrator or editing MFA settings, users with a registered passkey get a "Confirm with passkey" button above the password field. User verification is always required, the token it produces is single-use and bound to the user, the backend session and the Sudo Mode claim, and the password field stays as a fallback. Install tool password mode is not affected.
