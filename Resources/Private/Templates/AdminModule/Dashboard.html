No passkeys have been registered yet. Follow these steps to get started:

  1. Review extension settings — Go to Admin Tools > Settings > Extension Configuration > nr_passkeys_be and verify the Relying Party settings.
    Relying Party ID is currently auto-detected as {configRpId}. For production, consider setting it explicitly.
  2. Register your own passkey first — Go to your User Settings > Passkeys tab and register a passkey to verify the setup works on your device.
  3. Set a pilot group to "Encourage" — Use the group table below to set a small group (e.g., your admin team) to Encourage. Users will see a dismissible banner prompting them to register a passkey.
  4. Roll out gradually — See the Help tab for a full rollout guide covering all enforcement levels and recovery procedures.
Both Relying Party ID and Origin are auto-detected (currently {configRpId}). For production environments with multiple domains or reverse proxies, consider setting these explicitly in Admin Tools > Settings > Extension Configuration.
